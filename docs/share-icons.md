# Checklist social-sharing icons

The orbital sharing roller uses these compact glyphs from `public/share-icons/`.
Every asset has a `0 0 24 24` view box and a white fill for the roller's dark
surfaces. They contain no label, marketing tile, script, font or remote resource.
The visible translated service name supplies the accessible label; image elements
should use an empty `alt` when that same name is already present.

The Bootstrap paths are uniformly scaled from 16 x 16 to 24 x 24; Simple Icons paths
retain their 24 x 24 coordinates. Paths are unchanged, and only sizing, fill and
accessibility wrappers were normalized. No runtime icon dependency was added.

Hacker News uses the familiar Y Combinator mark. `native.svg` is Bootstrap's
box-arrow-up share glyph; `copy.svg` is its overlapping-pages copy glyph.
The hub's `public/social/` files combine glyphs with large labels and were
inspected as references; those composed tiles are not used by this roller.

## Validation

The collection contains exactly the 21 `SHARE_SERVICES` ids and the `native`
and `copy` actions. XML parsing, static-SVG checks, matching view boxes and
manifest hashes were verified after formatting. The parent roller's build and
browser checks own integration, image decoding and interaction coverage.
